# Vision-X
FACE DETECTION and HANDS MOVEMENT DETECTION WITH STRINGS USING HTML,CSS, and JavaScript.

# About the Project
Vision-X is a web-based computer vision project that focuses on real-time face detection and hand movement detection using webcam input. The project is developed using HTML, CSS, and JavaScript to create an interactive and user-friendly interface. It captures live camera input and provides visual feedback based on the detected face and hand movements. The project demonstrates the practical application of web technologies in building interactive computer-vision-based applications.

# Technologies Used
- HTML
- CSS
- JavaScript

# Features
- Real-time face detection
- Hand movement detection
- Webcam-based interaction
- Interactive and user-friendly interface
